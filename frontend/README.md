# Frontend - Gestión de Compras

Aplicación frontend para gestión de Planes Anual de Compras (PAC).

## Tecnologías

- React 18.2.0
- TypeScript 5.1.3
- Vite 4.4.0
- MUI (Material UI) 5.13.7
- Zustand 4.3.9
- Axios 1.4.0
- React Router DOM 6.14.1

## Inicio Rápido

```bash
npm install
npm run dev
```

## Variables de Entorno

- `VITE_API_URL`: URL base del API de PAC (default: http://localhost:8002)
- `VITE_AUTH_URL`: URL base del servicio de autenticación (default: http://localhost:8001)
- `NODE_ENV`: Entorno de ejecución (development/production)
